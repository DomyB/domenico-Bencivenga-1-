# Campus Connect

Campus Connect is a lightweight web app that helps university students coordinate campus meetups and stay updated on what's happening around the city. The interface is protected by a simple university access password so that events stay within the student community.

## Features

- **Password Gate:** Students must enter the shared university password before accessing the platform.
- **Plan Meetups:** Create on-campus gatherings with titles, locations, date/time, and descriptions. Saved meetups persist locally in the browser.
- **Search & Filter:** Quickly find gatherings by title or location.
- **City Events:** Browse curated city-wide events with filters for category and date.
- **Popular Bars:** Discover go-to student bars and hangouts with entry details and highlights.

## Getting Started

1. Open `index.html` in a modern browser.
2. Enter the university password: `campus-connect`.
3. Start planning meetups or exploring events around campus!

> Tip: Meetups are stored in your browser's `localStorage` so they will remain available the next time you open the app on the same device.
